    Configuración de conexión

    Esta URL es la “llave” que conecta la página con la carpeta de Drive.
    1. Abre script.google.com → Nuevo proyecto y pega el archivo Code.gs.
    2. Cambia ACCESS_CODE (y ROOT_FOLDER_ID si ya tienes la carpeta).
    3. Ejecuta setup una vez y acepta los permisos.
    4. Implementar → Nueva implementación → Aplicación web · Ejecutar como Yo · Acceso Cualquier persona.
    5. Pega aquí la URL que termina en /exec.
    Para que todos los docentes la tengan sin configurar nada, pega la URL también en SCRIPT_URL al inicio del código de este HTML.
